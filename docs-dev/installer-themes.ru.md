# Темы и стили установщика

[English](installer-themes.md) | **Русский**

React-интерфейс обёрнут в `FluentProvider` из Fluent UI. [`App.tsx`](../../voboost-installer/src/App.tsx) выбирает `webLightTheme` или `webDarkTheme` по системной настройке `prefers-color-scheme: dark`. [`useDarkMode`](../../voboost-installer/src/hooks/useDarkMode.ts) читает начальное значение, отслеживает изменения и удаляет обработчик при размонтировании.

Палитры для отдельных платформ в [`src/themes`](../../voboost-installer/src/themes) остаются вспомогательными функциями. `getTheme` выбирает палитру macOS для `macos` и палитру Windows в остальных случаях, но приложение его не вызывает. Эти функции не определяют активную тему приложения. Определение платформы и USB в `usePlatform` независимо используется в подсказках по подключению.

Храните стили рядом с компонентами в CSS и соблюдайте существующие BEM-имена. [`App.css`](../../voboost-installer/src/App.css) задаёт фон и границу через цветовые токены Fluent и объявляет `--layout-horizontal-padding`. При изменении отступов, шрифтов и цветов опирайтесь на текущие стили компонентов и токены темы.

Проверяйте интерфейс в светлой и тёмной темах и при поддерживаемых размерах окна. Одна проверка frontend не подтверждает внешний вид упакованного приложения.
