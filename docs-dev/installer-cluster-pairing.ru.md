# Защищённое сопряжение приборки

[English](installer-cluster-pairing.md) | **Русский**

Сопряжение реализовано существующим Rust-модулем [cluster_pairing.rs](../../voboost-installer/src-tauri/src/cluster_pairing.rs). Устаревший независимый генератор удалён. При установке процесс подготовки приборки вызывает `cluster_pairing::prepare`, а сохранённые защищённые материалы открывает через `cluster_pairing::resume`; отдельной команды подготовки больше нет.

Реализация создаёт независимые ключи подписи Android и QNX для устройства, случайные идентификатор пары и эпоху полномочий, секрет IPC, транспортные credentials и конфигурацию приборки. Ключи подписи продукта не заменяются. На macOS операции с сертификатами используют системный `/usr/bin/openssl`; отдельная установка OpenSSL или Python не нужна.

Каталоги имеют права 0700, закрытые файлы — 0600. Существующий результат сохраняется; при неудачной генерации удаляется только созданный ею новый каталог. Credentials нельзя помещать в логи или Git. Подготовка сама по себе не подтверждает доставку, восстановление после загрузки или работу в машине.

Существующие Rust-тесты проверяют согласованность wire/config, независимость ключей, сертификаты и PKCS#12, права файлов, удаление промежуточных материалов, сохранение существующего результата, неверные профили и очистку после настоящей ошибки криптографической операции. Запускать через настроенное Cargo-окружение установщика:

```sh
cargo +1.98.0 test --manifest-path src-tauri/Cargo.toml --offline --lib cluster_pairing::tests
```

`TMPDIR` должен находиться внутри проекта; используйте общий Cargo target установщика. Криптографические тесты требуют macOS и удаляют временные credentials, созданные под `src-tauri`.
