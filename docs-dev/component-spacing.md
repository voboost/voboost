# Component spacing inputs

**English** | [Русский](component-spacing.ru.md)

The Settings spacing accessor is generated from reviewed component source snapshots in [`tools/component-spacing`](../../voboost-agents/tools/component-spacing). These are build inputs; their component Views are not compiled or loaded into Settings. `provenance.json` records original paths and snapshot identities.

The [Java generator](../../voboost-agents/tools/java/ru/voboost/spacing/ComponentSpacingGenerator.java) verifies the fixed inventory, extracts exact declarations and the checkbox branch with/without a description, and rejects missing, ambiguous or changed inputs. Normal generation does not need a sibling components checkout.

Run from `voboost-agents`:

```sh
./gradlew --offline generateComponentSpacing verifyComponentSpacing
./gradlew --offline test --tests ru.voboost.ui.qinggan.ComponentSpacingProvenanceTest
./gradlew --offline :stubs:settings:testDebugUnitTest --tests ru.voboost.ui.qinggan.SectionSpacingTest
```

`compileJava` runs generation before compilation. Output is `build/generated/sources/componentSpacing/ru/voboost/ui/qinggan/ComponentSpacing.java`; do not edit it. Checks cover source extraction, generated bytes and fixture layout measurements. Host evidence does not replace live screenshots or physical acceptance. Preserve hardware `_1original.png` evidence.

For an intentional defaults update, compare snapshot/provenance changes with the actual components source before regeneration. The Java producer implements `--verify-source <components>` and `--refresh <components>` with `--project <agents>`; the current Gradle task exposes generation only, with no maintained refresh wrapper.

Snapshots retain their nested [Apache 2.0 license](../../voboost-agents/tools/component-spacing/LICENSE) and [NOTICE](../../voboost-agents/tools/component-spacing/NOTICE); these do not replace the agents repository license.
