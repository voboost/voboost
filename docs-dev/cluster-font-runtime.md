# Native font runtime

**English** | [Русский](cluster-font-runtime.ru.md)

`src/product.cpp` is the minimal preserved Runtime2/Agent3 lifecycle port. It admits authorized modules, reconciles derived desired state and keeps module code loaded after stop. The only native beta1 module is the existing logical `font-cyrillic` agent's QNX implementation; it creates no second checkbox or intent.

The native descriptor uses the logical process name `gauge`. The shared catalog parser binds this QNX target to the executable `/usr/bin/gauge`; `gauge_normal.kzb` names the theme resource and does not imply an executable named `gauge_normal`. The producer manifest carries the QNX/cluster/Agent3 tuple and the exact native artifact identity; executable admission additionally requires the protected startup configuration and verified OEM build identities. Emulator launch aliases are not physical vehicle profiles.

`./gradlew buildNativeCluster` cross-builds `build/cluster/product/libvoboost-runtime-cluster.so` and `libagent-font-cyrillic.so` with NDK 29.0.14206865 and the exact SDK2/Agent3 header hashes in `sdk-v3.lock.json`. `-PclusterSdkDirectory=<path>` selects an exported SDK. Release orchestration may provide an already-built native directory with `-PclusterNativeDirectory=<path>`; catalog and bundle verification bind its exact bytes.

The font agent requires the size-detected completion extension of `vbc_font_loader_v1` and the retained libkzcoreui build identity `4078ac45f735e41b1c76c262ebd9ba15`. Missing capability or identity fails admission. It qualifies every input by exact SHA-256, applies bounded SFNT structural repair, verifies the exact output SHA-256, and retains at most two static buffers totaling 3,357,136 bytes for the process lifetime. Stop removes future callbacks and reports reload-required after any transformed buffer was returned. It never unloads buffers still borrowed by FreeType faces. The extension reports the original `FT_New_Memory_Face` return and whether it created a face. `Applied` requires a successful corrected face, with its exact output digest, and no previous or in-flight face at hook installation; otherwise the state remains reload-required. A successful pre-UI load is retained and reported when the OEM UI becomes ready. Disabled modules do not install callbacks.

Host gates cover Java/native synthetic parity, malformed/unknown/bounded input, SHA-256 padding, callback ownership, successful/failed face completion, callback draining, preexisting-face reload semantics and Runtime2 lifecycle. `tools/verify-native-font-oem.py --kzb <external-retained-gauge_normal.kzb> --report build/evidence/native-font-oem.json` independently locates exact font identities and verifies both exact output identities in memory. No extracted OEM fonts are written or included in the bundle.

The original Free 6.0.3 system image (SHA-256 `ed32a05382848e0fb63cb33cdf0de55ec3d088f37aad21637b24c12e22a7a6bf`) contains libkzcoreui SHA-256 `954ef479aaa2c4851bc720f28ed4d192251912dd70db21506d85daa6c3284030`; its KZB font loader calls `FT_New_Memory_Face@plt` at RVA `0x43d094`, and its dynamic table has NOW without SYMBOLIC. This supports a loader-interposition candidate only. Actual QNX resolution, original-call counts, face loading, resource reload and physical vehicle behavior remain unverified. The original Free 6.0.3 `gauge_normal.kzb` (SHA-256 `2f0a9f0efe798b6ebaf6c299ccd58453ea4295c864f8d725ffd6ad99369620a7`) passed both exact native/Java font transformations on the host. This establishes static input compatibility, not QNX runtime acceptance. Synchronous constructor reconciliation runs before returning to OEM startup, while prior dependency-constructor face loads still require reload. Automatic gauge restart is not implemented.
