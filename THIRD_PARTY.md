# Third-party materials

The root MIT license applies to original Voboost work. It does not relicense external libraries, their modifications, original copyright notices, or identified OEM materials. Preserve the applicable upstream notices when distributing those components. Build and test dependencies retain their own licenses even when they are absent from a release binary.

Rust release-tooling dependencies are pinned in release/Cargo.lock; Node dependencies in package-lock.json. Their individual licenses and notices remain applicable when their code is distributed. Gradle, Android platform and OEM inputs in sibling components are not relicensed by this repository. The OEM screenshot tools/tests/fixtures/launcher132-first-apps-page.png depicts third-party UI and is not included in the Voboost MIT grant.

Logo assets sourced from voboost-logo are outside this repository’s MIT grant and retain the license supplied with those assets. The logo licensing decision is separate from the current code migration.
