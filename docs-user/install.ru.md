# Установка

[English](install.md) | **Русский**

Voboost устанавливается с компьютера через USB. Понадобятся [кабель с передачей данных](https://voyahchat.ru/cable) и включённая в машине [отладка по USB](https://voyahchat.ru/usb).

## Подготовка

- Voyah Free или Dreamer с Android 9 или 11
- компьютер с Windows 10/11, macOS или Linux
- [USB-кабель с передачей данных](https://voyahchat.ru/cable); надёжнее всего работает кабель USB 2.0 Type-A — Type-A, а для порта Type-C нужен переходник

## Установка

1. Включите [отладку по USB](https://voyahchat.ru/usb) в настройках машины

2. Подключите [USB-кабель с передачей данных](https://voyahchat.ru/cable) к порту USB Type-A в машине; если таких портов два, используйте ближайший к водителю

3. Если установщик обнаружил несколько устройств, выберите нужную машину

4. Продолжите установку на [Windows](#windows), [macOS](#macos), [Linux](#linux) или через [командную строку](#командная-строка)

> После начала установки не отключайте кабель и не выключайте машину, пока установщик не сообщит об успешном завершении.

## Windows

1. Скачайте [voboost-installer-1.0.0-beta1.exe](https://voboost.ru/voboost-installer-1.0.0-beta1.exe)

2. Убедитесь, что в Windows установлен Microsoft Edge WebView2 Runtime. Он нужен только графическому интерфейсу; установщик не скачивает и не устанавливает WebView2

3. Запустите `voboost-installer-1.0.0-beta1.exe`. Windows предупредит о неизвестном издателе; продолжайте, только если файл скачан по ссылке выше

4. Прочитайте лицензионное соглашение и подтвердите его принятие

5. Выполняйте указания установщика и дождитесь успешного завершения

Один portable EXE содержит весь продукт. Во временный закрытый каталог извлекаются только `adb.exe`, `AdbWinApi.dll` и `AdbWinUsbApi.dll`.

## macOS

1. Скачайте [voboost-installer-1.0.0-beta1.dmg](https://voboost.ru/voboost-installer-1.0.0-beta1.dmg)

2. Откройте `voboost-installer-1.0.0-beta1.dmg` и запустите `Voboost Installer`

3. Если macOS заблокирует запуск, откройте «Системные настройки» → «Конфиденциальность и безопасность», подтвердите открытие `Voboost Installer` и запустите его ещё раз

4. Прочитайте лицензионное соглашение и подтвердите его принятие

5. Выполняйте указания установщика и дождитесь успешного завершения

В корне образа находятся `Voboost Installer.app` и ссылка `voboost-installer` на тот же универсальный исполняемый файл. В пакет входит один universal ADB для Apple Silicon и Intel.

## Linux

Для Linux нужен системный ADB: команда `adb` должна быть доступна в `PATH`.

Скачайте `voboost-installer-1.0.0-beta1.tar.bz2`:

```sh
curl -O https://voboost.ru/voboost-installer-1.0.0-beta1.tar.bz2
```

Архив содержит один консольный файл `voboost-installer`. Распакуйте его:

```sh
tar -xjf voboost-installer-1.0.0-beta1.tar.bz2
```

Запустите установку:

```sh
./voboost-installer -i
```

## Командная строка

Установку можно выполнить без графического интерфейса через командную строку на Windows, macOS и Linux. `-i` — короткая форма `--install`.

```sh
voboost-installer -i
```

Установка не показывает обязательный экран лицензии и не запрашивает согласие. Тексты лицензий и уведомления о сторонних компонентах остаются в поставке.

```sh
voboost-installer -i
```

## Чистая установка и обновление

Чистая установка через `--install` удаляет прежний Voboost и его настройки. Установщик по возможности продолжает прерванную установку того же проверенного комплекта. Для новой установки он сам запускает или продолжает удаление, проверяет Android и, если применимо, приборку, а затем устанавливает новый комплект в том же вызове. Если обязательную проверку пройти не удалось, установщик сообщает причину до передачи нового комплекта в машину. На профилях, где нужна проверка QNX, используйте настольный установщик с поддержкой приборки.

Чтобы сохранить настройки установленного Voboost, используйте `voboost-installer --update`. Подробнее на странице [обновлений](updates.ru.md).

## Что происходит с машиной

Для первого запуска `voboost-daemon` нужны права root и отдельные правила SELinux. Перед изменениями установщик сохраняет исходное состояние текущей прошивки, временно переводит SELinux в permissive, устанавливает Voboost и возвращает SELinux в enforcing, добавив минимальные правила для Voboost.

Во время установки мультимедиа перезагрузится дважды. Связь по ADB временно пропадёт, но операция продолжится в машине, а установщик снова покажет её состояние после восстановления связи.

## Если установка прервалась

Не запускайте другой выпуск Voboost и не удаляйте файлы вручную. Снова запустите ту же версию `voboost-installer`, выберите тот же выпуск и подключите ту же машину: установщик продолжит уже начатую в машине операцию или покажет причину остановки.

## Результат

Установка завершена, когда `voboost-installer` сообщает об успехе, `voboost-daemon` запускается после перезагрузки, а в настройках машины появляется вкладка Voboost. По умолчанию все пользовательские агенты выключены, [их надо включить](usage.ru.md).

Если вкладка не появилась — [скачайте логи](logs.ru.md).
