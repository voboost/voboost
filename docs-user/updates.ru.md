# Обновление

[English](updates.md) | **Русский**

Voboost обновляется как единый продукт. Новый выпуск может изменить Android-приложение, один или несколько агентов, native runtime, установщик, документацию или только release metadata. Версия обозначает полный комплект, а не отдельный компонент.

## Автоматическое обновление

Android-приложение проверяет небольшой подписанный `channel.json`, а затем один полный подписанный `voboost.json`. Оно скачивает только файлы, точная identity которых изменилась. Агенты поставляются отдельными файлами и не встроены в `voboost-app.apk`: изменение одного агента не требует скачивать или переустанавливать APK, если байты APK не изменились.

Приложение только скачивает и подготавливает файлы. `voboost-daemon` повторно проверяет полный комплект, решает, какие агенты подходят машине, и выполняет root-owned activation.

Приложение планирует проверки через JobScheduler и продолжает прерванные загрузки. Демон хранит в immutable generation все подписанные файлы агентов; применимость к машине влияет только на выбор и загрузку файлов в процессы. Поэтому после изменения прошивки демон может выбрать уже установленный агент, не скачивая повторно файл с тем же SHA-256.

## Перезагрузка

Agent-only изменения можно подготовить без переустановки Android-приложения. Перезагрузка требуется только тогда, когда изменившиеся байты нельзя безопасно активировать в работающих процессах: например, обязательный процесс уже загрузил прежнее generation агентов или изменился native runtime. Voboost ждёт подтверждения и не перезагружает мультимедиа автоматически.

## Ошибка и откат

Предыдущий выпуск остаётся активным, пока не проверена каждая изменившаяся часть. Если активация завершается ошибкой, Voboost сохраняет или восстанавливает прежнее проверенное generation и native files. Не удаляйте файлы из `/data/voboost` вручную: соберите [логи](logs.ru.md) и используйте доступное для наблюдаемого состояния действие восстановления в установщике.
