# Быстрый старт

[English](quick-start.md) | **Русский**

Скачайте `voboost-installer`, установите Voboost и включите нужных агентов. Для установки понадобятся компьютер, [USB-кабель с передачей данных](https://voyahchat.ru/cable) и включённая [отладка по USB](https://voyahchat.ru/usb).

## Скачать

Скачайте `voboost-installer` для своего компьютера:

- [Windows](https://voboost.ru/voboost-installer-1.0.0-beta1.exe) — Windows 10 или 11
- [macOS](https://voboost.ru/voboost-installer-1.0.0-beta1.dmg) — универсальный установщик для Apple Silicon и Intel
- [Linux x86_64](https://voboost.ru/voboost-installer-1.0.0-beta1.tar.bz2) — ADB не входит в архив, используется системный

Windows поставляется одним portable EXE. Для графического интерфейса нужен установленный Microsoft Edge WebView2 Runtime; командная строка работает без WebView2. Установщик извлекает во временный закрытый каталог только `adb.exe`, `AdbWinApi.dll` и `AdbWinUsbApi.dll`.

В образе macOS находятся `Voboost Installer.app` и корневая ссылка `voboost-installer` на тот же универсальный исполняемый файл. В пакет входит один universal ADB для Apple Silicon и Intel.

Архив Linux содержит один консольный файл `voboost-installer`. До запуска установите системный ADB и убедитесь, что команда `adb version` работает.

Windows и macOS могут предупредить о неизвестном издателе. Продолжайте, только если пакет скачан с официальной страницы Voboost.

## Установить

1. [Включите отладку по USB](https://voyahchat.ru/usb) в настройках машины
2. Подключите компьютер к машине с помощью [кабеля](https://voyahchat.ru/cable)
3. Запустите `voboost-installer` и выберите **Начать установку**
4. Прочитайте лицензионное соглашение
5. Подтвердите принятие лицензионного соглашения и установку
6. Выполняйте указания установщика и дождитесь успешного завершения

Во время перезагрузки мультимедиа связь временно пропадает. Если кабель отключился, подключите его снова и не начинайте новую установку: установщик продолжит найденную операцию.

[Подробнее об установке](install.ru.md).

## Использовать

1. Откройте вкладку Voboost в настройках машины
2. Включите нужные агенты

[Подробнее об использовании](usage.ru.md).

## Удалить

1. Откройте вкладку Voboost в настройках машины
2. В разделе «Удаление» нажмите **Удалить**
3. Подтвердите удаление

После подтверждения вкладка Voboost исчезнет, а удаление продолжится в машине. Мультимедиа будет перезагружаться только при необходимости; уведомления о завершении в машине не будет.

[Подробнее об удалении](uninstall.ru.md).
