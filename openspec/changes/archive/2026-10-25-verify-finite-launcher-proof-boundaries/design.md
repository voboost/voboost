# Design

Reuse nativePointerRequest and launcherPageDrag. Compare effective original visibility over the union of observed original identities with default-true semantics. Reacquire complete native pages and retain one target lifetime across drag/readback. Save the changed full inventory for external reboot. Keep liveLocale NOT_RUN: this driver does not safely establish enabled translation authority and checked system Russian selection. Checkpoint flags cannot establish current language proof.

# Evidence boundary

Host fixture tests validate driver admission only. Actual move, reboot, conditional locale and OEM animation require an authorized existing-session runtime run. No VM is started by this change.
