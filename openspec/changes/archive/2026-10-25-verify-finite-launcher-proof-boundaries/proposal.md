# Why

The finite launcher runtime driver can accept a user bulk action that corrupts original visibility and can report reboot order success without ever moving an item. It also includes no conditional Russian client proof.

# What Changes

Require original-state isolation and an actual fenced move with complete changed-order receipts before the reboot checkpoint. Expose conditional language as unavailable and keep broad completion partial until its independent runtime dependency is verified.

# Impact

Only product test tooling and its acceptance contract change. No agent, packaged payload, VM lifecycle, system locale or persistent device policy changes.
