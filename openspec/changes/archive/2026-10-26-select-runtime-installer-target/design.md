# Design

Use the existing runtime serial as the sole --device value in each fixed observation, log and acceptance argv. Exact four-argument proof guards retain their shape and require the canonical flag. Old --device-serial evidence does not satisfy the current contract. Native USB uses the same device flag without a port option.

Keep existing config, provider IPC and Installer response schemas. Diagnostic server selection belongs to Installer and its Voyemu compatibility contract. Product consumers add no port field, alias, default or target helper.
